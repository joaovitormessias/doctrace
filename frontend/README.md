# DocTrace — interface

Interface React, TypeScript e Material UI do assistente de documentos contábeis.

Para instalação, configuração de ambiente, ingestão e demonstração, consulte o [guia principal](../README.md).

## Desenvolvimento local

Com Node.js 24, execute `npm ci` e `npm run dev` nesta pasta. Configure `VITE_API_URL` e `VITE_N8N_INGEST_URL` conforme o ambiente; para compartilhar por link, use o Compose de demonstração descrito no guia principal.

## Verificações

```bash
npm run build
npm run lint
```
